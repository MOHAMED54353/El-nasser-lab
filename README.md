# El-Nasser Medical Laboratory

An Arabic medical laboratory website developed as a **Vibe Coding training project**.

## Overview

A simple, responsive website for a medical laboratory, designed to provide visitors with information about laboratory services and make it easier to explore available tests.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Arabic RTL interface
* Responsive design
* Medical laboratory services
* Clean and user-friendly layout

## Project Type

Vibe Coding Training Project
